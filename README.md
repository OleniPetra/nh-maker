# Static Creo

Внутренний инструмент для работы со статичными рекламными креативами: разбор готовых
креативов vision-моделью, генерация новых по накопленному опыту и четыре рабочих раздела
для сборки итоговых файлов и видео.

Одно FastAPI-приложение отдаёт и API, и весь фронтенд. Фронтенд — статические HTML-страницы
без сборки и без фреймворков: ни npm, ни бандлера в проекте нет.

## Как устроено

Точка входа одна — `scripts/review_server.py`. Она поднимает FastAPI на порту **8765** и
подключает остальные разделы как `APIRouter` с собственными префиксами:

```
scripts/review_server.py     — приложение + Dashboard (/, /dashboard, /api/*)
  ├── audiopng/server.py     — router с префиксом /audiopng
  ├── competitors/api.py     — router с префиксом /competitors
  └── headline/headline_api.py — router с префиксом /headline
```

Статика монтируется рядом с роутерами: `/audiopng`, `/competitors`, `/headline` отдают свои
`static/index.html`, а `/static-shared` — общие фронтенд-модули из `scripts/shared/`.

Корень `/` редиректит на `/audiopng/`.

### Про имена модулей

`competitors/api.py` и `headline/headline_api.py` названы по-разному намеренно. Оба делают
`import server as audiopng`, полагаясь на то, что модуль audiopng уже лежит в
`sys.modules['server']`. Если бы файл headline тоже назывался `api.py`, второй
`import api as ...` вернул бы уже закэшированный модуль competitors вместо нужного — ошибка
была бы молчаливой. Порядок импортов в `review_server.py` тоже важен и зафиксирован
комментарием.

### Фоновые задачи

Генерация изображений идёт минуты (GPT Image 2 замерялся на ~158 секунд), а Cloudflare Tunnel
обрывает одиночный проксируемый запрос примерно на 100-й секунде и отдаёт свою HTML-страницу
вместо JSON. Поэтому все долгие вызовы устроены как фоновые задачи:

1. `POST /api/generate…` сразу возвращает `{"job_id": "..."}`
2. фронтенд опрашивает `GET /api/job/{job_id}` раз в 2 секунды
3. каждый отдельный HTTP-запрос укладывается в доли секунды независимо от длины самой работы

Хранилище задач общее (`audiopng._JOBS`), все три раздела переиспользуют его хелперы
`_start_async_job` / `_get_job`.

## Разделы

### Dashboard

`/dashboard` — три вкладки поверх `db/creatives.db` и папки `Input/`.

**Creatives.** Сводная таблица из трёх источников, объединённых по имени файла:
`Input/images/`, `Input/creatives.csv` и `db/creatives.db`. Для каждой строки показывается
превью, ветка (`certif` / `claude` / `aigen`), оценка 1–3, заметка маркетолога и статус:

| Статус | Значение |
|---|---|
| `new` | файл есть на диске, в базе ещё нет |
| `processed` | обработан и лежит в базе |
| `missing_file` | есть в базе, файл с диска удалён |
| `csv_orphan` | строка в CSV без файла |

Отдельно помечается «заметка изменилась — обновите БД»: текущий текст заметки не совпадает
с хэшем, с которым креатив попал в базу.

Оценки, ветки и заметки правятся прямо в таблице и уходят в `Input/creatives.csv` по кнопке
«Сохранить всё». Кнопка «Обновить БД» запускает `ingest_creatives.py` фоновым процессом с
живым логом.

**Generate.** Собирает бриф на новый креатив: выбирается ветка, опциональная подсказка и
флаг «учитывать историю». LLM возвращает концепцию, копирайт (заголовок, подзаголовок, CTA,
подписи шагов), компактный резонинг из трёх частей — что переиспользовано, чего избегали,
что нового и почему — и промпты под конкретные модели.

У каждого промпта две кнопки: **Копировать** и **Отправить на генерацию** — вторая
перебрасывает промпт в AudioPng → AI Gen с уже выбранной под него моделью.

**History.** Все ранее сгенерированные брифы с фильтром по ветке, просмотром и удалением.

### AudioPng

`/audiopng/` — сборка финальных креативов и видео 9:16. Шесть колонок.

**1. Images.** Три режима загрузки:

- **Upload** — обычная загрузка с выпадающим списком соотношений. `Auto` (по умолчанию)
  оставляет размер и пропорции исходника нетронутыми; остальные растягивают под выбранный
  формат без обрезки:

  | | |
  |---|---|
  | `9:16` | 1080×1920 |
  | `16:9` | 1920×1080 |
  | `1.91:1` | 2063×1080 |
  | `1:1` | 1080×1080 |
  | `4:5` | 1080×1350 |
  | `3:4` | 1080×1440 |

- **Upload 3:4** — готовый save-zone 1080×1350, который сервер сам дорисовывает
  сверху и снизу до 1080×1920.
- **AI Gen** — генерация по текстовому промпту (Nano Banana 2 или GPT Image 2) с тем же
  автоматическим аутпеинтом.

**2. Overlay (общий).** Логотипы и дисклеймеры из `audiopng/templates/`. Файлы, названные
`<base>_light.png` и `<base>_dark.png`, автоматически объединяются в одну запись с бейджем
`AUTO`: под каждую картинку подбирается вариант по её яркости — тёмный фон получает светлый
оверлей и наоборот.

**3.1 / 3.2 Overlay Logo / Disclaimer (по каждой картинке).** Для каждого файла — превью с
двумя вертикальными ползунками: `H` (положение по высоте) и `S` (масштаб). Первая карточка
помечена `★ master`: её изменения транслируются на все остальные, остальные правятся
независимо.

В углу превью — кнопка переключения цвета оверлея: автоопределение светлого/тёмного иногда
ошибается, и его можно поправить вручную отдельно для логотипа и для дисклеймера.

**4. Audio.** Дорожки голоса и музыки с громкостями. Длина видео берётся из голоса; музыка
короче — зацикливается, длиннее — обрезается. Если загружена **только музыка**, появляется
поле длительности (по умолчанию 30 секунд) — иначе трёхминутный фоновый бед дал бы
трёхминутное видео.

**5. Preview & Export.** Предпросмотр и список результатов.

Две кнопки запуска: **RUN** рендерит видео (требует аудио), **RUN IMAGE ONLY** собирает
только картинки с оверлеями. Рендер идёт в браузере через WebCodecs с ffmpeg.wasm как
запасным вариантом.

#### Аутпеинт

Общий шаг для Upload 3:4 и AI Gen: save-zone 1080×1350 расширяется до 1080×1920.
Дорисовываются только верх и низ, весь текст и графика остаются в нетронутой центральной
полосе.

Алгоритм сначала смотрит на края. Если верхняя и нижняя полосы ровные (стандартное
отклонение ниже 8.0 — плашка, градиент, заливка), края просто растягиваются детерминированно:
бесплатно, мгновенно и без риска, что модель что-нибудь дорисует. Фактурные и фотографические
края уходят в `fal-ai/flux-2-pro/outpaint` — модель без маски и без промпта, которой нечего
галлюцинировать.

### Competitors Static

`/competitors/` — новые креативы в стиле референсов конкурентов, но со своим текстом.

**1. Наш креатив.** Одна или несколько картинок; из каждой vision-модель
(`anthropic/claude-haiku-4.5` через OpenRouter) вытаскивает только текст. Стиль и картинка
источника не используются. Каждый извлечённый текст попадает в свою карточку и правится
вручную. Извлечение идёт последовательно — пачка параллельных запросов упиралась бы в лимиты
OpenRouter.

**2. Референсы конкурентов.** Картинки, у которых берётся визуальный язык: палитра, фактура,
раскладка, стиль CTA.

**3. Модель.** Nano Banana 2, Nano Banana Pro или GPT Image 2.

**4. Preview & Export.** Результаты, выгрузка ZIP и кнопка «Отправить в NH» — передаёт готовые
картинки в AudioPng → Upload.

Одна генерация = один текст × один референс, то есть N текстов и M референсов дают N×M файлов.

Пайплайн из двух шагов. Сначала **LLM-прослойка** (`google/gemini-3.7-flash`, vision) смотрит на
референс и переводит его стиль в текстовое описание: настроение, типографика, палитра, иерархия,
принципы вёрстки, фон, декор, философия — только принципы, без содержимого. Затем это описание
вместе с нашим текстом и неизменяемыми правилами собирается в промпт, по которому **text-to-image**
модель рисует креатив 3:4, после чего он расширяется аутпеинтом до 9:16.

Ключевое: генератор картинки референса **не видит вообще**. Раньше сюда стояла edit-модель,
которой референс передавался напрямую, и она тянула из него не только стиль, но и содержимое —
в тестах дописывались подписи, подсмотренные у референса. Теперь копировать физически нечего.

У каждого результата две кнопки перезапуска с одинаковой иконкой и разными подписями:

- **Аутпеинт** — перегенерирует только расширение краёв, переиспользуя уже готовый save-zone.
  Платная генерация не повторяется.
- **Генерация** — перезапускает весь вызов заново с теми же текстом, референсом и моделью.

Контекст перезапуска хранится в самой записи результата, поэтому кнопки работают и после
удаления исходников из колонок, и после перезагрузки страницы.

> Собственный шейп (`720×960` → `720×1280`) объявлен локально в `competitors/api.py` и
> намеренно не берётся из констант audiopng: иначе правка размеров в одном разделе молча
> меняла бы пайплайн другого.

### Headline

`/headline/` — точечная замена только заголовка в готовом креативе. Body copy, CTA, вёрстка,
изображения и брендинг остаются нетронутыми.

**1. Заголовки.** Два режима ввода:

- **Растущие поля** — новое поле появляется само, как только заполнено предыдущее
- **Список строк** — одно поле на всю высоту, каждая строка = отдельный заголовок

Слово или фраза в **квадратных скобках** выделяется акцентным цветом:
`Learn AI with [Claude]` → «Claude» будет отрисован контрастным цветом, скобки в результат
не попадают.

**2. Креативы.** Статичные креативы, в которых нужно заменить заголовок.

**3. Preview & Export.** Результаты, выгрузка и передача в AudioPng.

Одна генерация = один заголовок × один креатив (`fal-ai/nano-banana-2/edit`,
`aspect_ratio: auto` — пропорции исходника сохраняются). У каждого результата кнопка
**Генерация** для перезапуска. Отдельной кнопки аутпеинта здесь нет: в этом пайплайне такой
стадии нет вовсе, вызов модели один.

## Общие механизмы фронтенда

Всё в `scripts/shared/`, отдаётся по `/static-shared/`.

**`theme.css`** — дизайн-система: токены (цвета, радиусы, тени, шрифты, тайминги), база и
примитивы (`.btn`, `.u-badge`, `.col-step`). Единственный источник палитры; страницы поверх
описывают только свою раскладку. Уважает `prefers-reduced-motion`.

**`sidebar.js`** — навигация, единая для всех страниц. Странице достаточно иметь
`<div id="sc-sidebar-root"></div>`. Верхняя группа иконок прибита к верху экрана, нижняя
(вкладки дашборда) разворачивается стрелкой снизу. Подсветку активного пункта бар считает сам
и обновляет по `hashchange`.

**`session.js`** — сохранение состояния между перезагрузками, переходами и переключением
вкладок. IndexedDB, а не localStorage: в состоянии лежат `File`/`Blob` на десятки мегабайт.
Страница регистрируется через `NHSession.attach(pageId, collect, restore)`, модуль берёт на
себя дебаунс, дозапись при скрытии вкладки, обработку переполнения квоты и кнопку «Сбросить».
У каждой страницы свой ключ — сброс одной не трогает остальные.

Не сохраняются: `blobUrl` (протухают после перезагрузки, пересоздаются из `File`) и записи в
процессе генерации (их задачу на сервере уже не отследить, карточка висела бы вечным
спиннером).

**`handoff.js`** — передача данных между страницами. Картинки — через IndexedDB
(`stage`/`consume`), промпт с моделью — через sessionStorage (`stagePrompt`/`consumePrompt`).
Используется кнопками «Отправить в NH» и «Отправить на генерацию».

> При правке общих файлов нужно поднимать версию в query-параметре подключения
> (`sidebar.js?v=6`, `theme.css?v=2`) на всех страницах: Cloudflare и браузеры не
> перепроверяют статику с тем же URL внутри окна кэширования.

## Установка и запуск

Нужен Python 3.10+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Создать `.env` в корне:

```
OPENROUTER_API_KEY=...
FAL_KEY=...
```

Запуск:

```bash
python3 scripts/review_server.py
```

Открыть `http://127.0.0.1:8765`.

Папки с данными (`Input/images/`, `db/`, `library/`, `generated/`) создаются по мере работы и
в репозиторий не попадают.

## Деплой

Приложение работает на домашнем сервере под systemd и публикуется наружу через именованный
